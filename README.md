# Chain-of-Thought Prompting

## Overview

This project demonstrates how **Chain-of-Thought Prompting** can improve the quality of responses generated by a Large Language Model (LLM). Instead of asking the model to provide a direct answer, the prompt encourages it to approach the problem in a structured manner by identifying key information, explaining the reasoning process, performing any necessary calculations, and then presenting the final answer.

The application uses the **Groq API** with the **Llama 3.3 70B Versatile** model to compare a standard prompt against a structured reasoning prompt, highlighting how prompt design can influence the clarity and organisation of AI-generated responses.
