# Debugging a Weak Prompt Through Iterative Testing

## Overview

This project demonstrates how **Prompt Engineering** can improve the quality of responses generated by a Large Language Model (LLM) through **iterative prompt refinement**.

Instead of accepting the first response produced by a weak prompt, we progressively improve the prompt by adding clearer instructions, defining the audience, specifying the desired output format, and introducing additional constraints. This process helps produce responses that are more accurate, structured, and useful.

The project uses the **Groq API** with the **Llama 3.3 70B Versatile** model to compare responses generated from four different versions of the same prompt.

# Project Workflow

```
                User Query
                     │
                     ▼
            Weak Initial Prompt
                     │
                     ▼
          Generate AI Response
                     │
                     ▼
      Evaluate Response Quality
                     │
                     ▼
      Improve the Prompt (Iteration 1)
                     │
                     ▼
          Generate New Response
                     │
                     ▼
     Add More Instructions & Context
                     │
                     ▼
      Improve the Prompt (Iteration 2)
                     │
                     ▼
          Generate Better Response
                     │
                     ▼
        Final Optimized Prompt
                     │
                     ▼
      High-Quality Structured Output
```
