# Prompting for Question Answering

## Overview

This project demonstrates how prompt engineering can improve the quality and reliability of answers generated by Large Language Models (LLMs). A carefully designed prompt instructs the models to answer questions using only the provided context, reducing the chances of generating unsupported information.

The application sends the same prompt to four different LLM providers:

- Groq (Llama 3.3 70B)
- OpenRouter (GPT-OSS-20B Free)
- Google Gemini 3.5 Flash
- NVIDIA NIM (MiniMax M3)

The responses from each model are displayed side by side in the terminal, allowing users to compare how different models interpret the same prompt while following identical instructions.
